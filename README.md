# 🎭 pnj_editor

**PNJ Editor for FiveM** — Un outil permettant de positionner précisément les PNJ et de leur attribuer des animations personnalisées sur votre serveur FiveM.

🔗 **GitHub :** [212Moor/pnj_editor](https://github.com/212Moor/pnj_editor)

## ✨ Présentation

`pnj_editor` est un projet destiné aux développeurs et créateurs de serveurs FiveM souhaitant faciliter la mise en place de PNJ dans leur environnement de jeu.

L'objectif est de simplifier le placement des personnages et la configuration de leurs animations afin de créer des scènes plus immersives et réalistes.

## 🚀 Fonctionnalités

- 📍 Modification de la position des PNJ.
- 🔄 Ajustement de l'orientation des personnages.
- 🎭 Attribution d'animations personnalisées.
- 🎬 Création de scènes et de mises en situation.
- 🛠️ Outil destiné à faciliter la création et la configuration des PNJ.

## 📦 Installation

1. Téléchargez le projet depuis le dépôt GitHub.
2. Placez le dossier `pnj_editor` dans le répertoire `resources` de votre serveur FiveM.
3. Ajoutez la ligne suivante dans votre fichier `server.cfg` :

   ```cfg
   ensure pnj_editor
   ```

4. Redémarrez votre serveur ou démarrez la ressource depuis la console.

## 🎮 Utilisation

Une fois la ressource installée, lancez-la sur votre serveur FiveM et utilisez les fonctionnalités prévues par le script pour positionner vos PNJ et leur attribuer des animations.

*Les commandes et les contrôles dépendent de l'implémentation actuelle du projet.*

## 🧰 Compatibilité

- **Plateforme :** FiveM
- **Jeu :** Grand Theft Auto V
- **Environnement serveur :** FXServer
